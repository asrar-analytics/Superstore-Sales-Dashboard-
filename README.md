# 📊 Superstore Sales Analysis & Dashboard

## 📌 Project Overview

This project analyzes the Superstore sales dataset to explore sales performance, profitability, customer behavior, regional performance, and business trends.

The project combines **Python, SQL, and Power BI** to transform raw sales data into meaningful business insights and an interactive dashboard.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall sales and profit performance.
- Identify the most profitable categories and sub-categories.
- Analyze customer sales and profitability.
- Compare sales and profit across regions.
- Explore sales and profit trends over time.
- Examine the relationship between discounts and profitability.
- Build an interactive Power BI dashboard to communicate key findings.
- Practice using SQL and data visualization techniques for business analysis.

## 📈 Key Insights

| Metric | Value |
|---|---|
| Total Sales | 2.30M |
| Total Profit | 285.99K |
| Total Orders | 5,009 |
| Total Quantity | 38K |

- **Sales growth:** Annual sales increased from approximately 480K in 2014 to approximately 730K in 2017.
- **Regional performance:** The West region recorded the highest sales, followed by the East region.
- **Category profitability:** Technology generated the highest profit among the categories, while Furniture recorded the lowest.
- **Interactive exploration:** The dashboard allows filtering by Region, Year, and Category to explore performance from different angles.

> All figures are based on the Power BI dashboard included in this repository.
